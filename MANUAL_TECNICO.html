1. Introdução e Arquitetura Geral — v2.0

3. j1939.rs — Protocol Stack J1939/CAN

Fundação do sistema. Codifica/decodifica frames CAN de 29 bits segundo SAE J1939 / ISO 11783.

3.1 Estrutura do CAN ID de 29 bits

O J1939 usa CAN 2.0B com identificadores estendidos de 29 bits. Cada bit tem um significado preciso: 
Bits: [28:26] [25] [24] [23:16] [15:8]      [7:0]
       PRI    RES  DP    PF      PS           SA
       3bits  1b   1b   8bits   8bits        8bits

PRI = Prioridade (0=mais alta, 7=mais baixa)
RES = Reservado (sempre 0)
DP  = Data Page (0 ou 1 — seleciona banco de PGNs)
PF  = PDU Format:
      PF < 0xF0 → PDU1 (peer-to-peer):  PS = Destino (DA)
      PF ≥ 0xF0 → PDU2 (broadcast):     PS = Group Extension (parte do PGN)
SA  = Source Address (endereço do remetente, 0x00-0xFD)

Por que endereços fixos? O J1939 define endereços fixos para tipos comuns de ECU na especificação SAE J1939-71. Isso permite interoperabilidade entre fabricantes diferentes. Um display de outro fabricante pode se comunicar com o ECM porque ambos conhecem o endereço 0x00 como "motor #1".

pub struct SpnDef {

Exemplo prático — SPN 190 (Engine Speed):
byte_offset=3, bit_offset=0, bit_length=16, factor=0.125, offset=0.0, unit="rpm"

RPM = 17440 × 0.125 = 2200 rpm

3.6 Struct J1939Frame — Frame CAN Decodificado

pub struct J1939Frame {
    pub timestamp: f64,      // Tempo da simulação em segundos
    pub raw_id:    u32,      // CAN ID bruto de 29 bits (ex: 0x0CF00400)
    pub priority:  u8,       // Prioridade extraída dos bits 28:26 (0-7)
    pub pgn:       u32,      // PGN calculado a partir do CAN ID
    pub sa:        u8,       // Source Address (quem enviou)
    pub da:        u8,       // Destination Address (0xFF = broadcast)
    pub data:      [u8; 8],  // Payload de 8 bytes (CAN clássico)
    pub dlc:       u8,       // Data Length Code (0-8, normalmente 8)
    pub decoded:   Vec<SpnValue>, // SPNs decodificados automaticamente
}

3.7 Função J1939Frame::from_raw() — Decodificação

pub fn from_raw(ts: f64, raw_id: u32, data: &[u8]) -> Self {
    // 1. Extrair Priority dos bits 28:26
    let priority = ((raw_id >> 26) & 0x7) as u8;

    // 2. Extrair Data Page do bit 24
    let dp = (raw_id >> 24) & 0x1;

    // 3. Extrair PDU Format dos bits 23:16
    let pf = ((raw_id >> 16) & 0xFF) as u8;

    // 4. Extrair PDU Specific dos bits 15:8
    let ps = ((raw_id >>  8) & 0xFF) as u8;

    // 5. Extrair Source Address dos bits 7:0
    let sa = (raw_id & 0xFF) as u8;

    // 6. Calcular PGN conforme tipo PDU:
    let (pgn, da) = if pf < 0xF0 {
        // PDU1: peer-to-peer — PS é o Destination Address
        // PGN NÃO inclui PS (seria diferente para cada destinatário)
        (((dp << 17) | ((pf as u32) << 8)) as u32, ps)
    } else {
        // PDU2: broadcast — PS é Group Extension, PARTE do PGN
        (((dp << 17) | ((pf as u32) << 8) | (ps as u32)) as u32, 0xFF)
    };

    // 7. Inicializar payload com 0xFF ("not available")
    let mut arr = [0xFFu8; 8];
    arr[..data.len().min(8)].copy_from_slice(&data[..data.len().min(8)]);

    // 8. Criar frame e decodificar SPNs automaticamente
    let mut f = J1939Frame { timestamp:ts, raw_id, priority, pgn, sa, da,
                             data:arr, dlc:data.len() as u8, decoded:Vec::new() };
    f.decode(); // extrai valores físicos de todos os SPNs conhecidos
    f
}

3.8 Função bits() — Extração de Bits

fn bits(data: &[u8], byte_off: usize, bit_off: u8, len: u8) -> u64 {
    let mut v = 0u64;
    for i in 0..len as usize {
        // Posição absoluta do bit no payload
        let abs = byte_off * 8 + bit_off as usize + i;
        let b = abs / 8;   // índice do byte
        let k = abs % 8;   // índice do bit dentro do byte (LSB-first)
        // Se o bit está em 1, setar o bit i do resultado
        if b < data.len() && (data[b] >> k) & 1 == 1 { v |= 1 << i; }
    }
    v
}
J1939 usa Little-Endian Byte Order e LSB-first bit numbering. O bit de menor peso (LSB) está no bit 0 do primeiro byte. Esta função implementa exatamente essa convenção.

4. can_gateway.rs — Barramento CAN Central

Simula o barramento físico CAN HS 500 kbps com arbitração, contadores de erro ISO 11898 e injeção de falhas.

4.1 Enum BusState — Estado do Barramento

pub enum BusState {
    ErrorActive,   // TEC < 128 E REC < 128 → operação normal
    ErrorPassive,  // TEC ≥ 128 OU REC ≥ 128 → envia "passive error flags"
    BusOff,        // TEC ≥ 256 → nó desconecta do barramento!
}
ISO 11898-1 Error Confinement:
Cada nó mantém dois contadores: TEC (transmit) e REC (receive).
• Erro de transmissão: TEC += 8
• Erro de recepção: REC += 1
• Frame bem-sucedido: TEC -= 1, REC -= 1
Quando TEC ≥ 256, o nó vai para BusOff e para de transmitir — proteção automática do barramento.

4.4 Método transmit() — Enfileirar Frame

pub fn transmit(&mut self, frame: J1939Frame) {
    self.tx_queue.push(frame); // Adiciona à fila — será processado em tick()
}

4.5 Método tick() — Arbitração e Despacho

pub fn tick(&mut self, dt: f64) {
    // 1. Verificar injeção de falhas
    if self.inject_bus_off { self.bus_state = BusState::BusOff; }

    // 2. ARBITRAÇÃO: ordenar por CAN ID (menor ID = maior prioridade)
    self.tx_queue.sort_by_key(|f| f.raw_id);
    // Isso replica a arbitração bitwise real do CAN:
    // nós com ID menor "vencem" automaticamente sem destruir o frame

    self.dispatched.clear();

    let frames: Vec<J1939Frame> = self.tx_queue.drain(..).collect();
    for frame in frames {
        // 3. Aplicar injeção de falha (descarta frame ocasionalmente)
        if self.inject_bit_error && self.total_tx % 100 == 0 { continue; }
        if self.inject_missing_ack && self.total_tx % 50 == 0 {
            // Nó registra erro de transmissão
            if let Some(n) = self.nodes.iter_mut().find(|n| n.source_addr == frame.sa) {
                n.record_tx_error(); // TEC += 8
            }
            continue;
        }

        // 4. Atualizar estatísticas do nó transmissor
        if let Some(n) = self.nodes.iter_mut().find(|n| n.source_addr == frame.sa) {
            n.last_tx_ts = frame.timestamp;
            n.record_success(); // TEC -= 1
        }

        // 5. Armazenar no log para análise e no buffer de despacho
        self.bus.push(frame.clone());    // para o CAN Monitor
        self.dispatched.push(frame);      // para os ECUs lerem no próximo tick
        self.total_tx += 1;
    }

    // 6. Calcular carga do barramento (amostrado a cada segundo)
    // 500 kbps, ~120 bits/frame → máx ~4166 frames/s
}

4.6 Método receive_for() — Filtro por Destinatário

pub fn receive_for(&self, sa: u8) -> impl Iterator<Item = &J1939Frame> {
    // Retorna apenas frames que este ECU deve processar:
    // 1. Frames broadcast (DA = 0xFF) de qualquer SA diferente do próprio
    // 2. Frames peer-to-peer endereçados especificamente para este SA
    self.dispatched.iter().filter(move |f| {
        f.sa != sa && (f.da == 0xFF || f.da == sa)
    })
}

Address Claiming — J1939-81:
1. ECU transmite frame PGN 60928 com SA=0xFE e dados = NAME (64 bits único)
2. Aguarda 250 ms monitorando o barramento por conflitos
3. Se outro nó reivindicar o mesmo SA: NAME menor (numericamente) vence
4. Perdedor tenta SA alternativo ou fica em SA=0xFE (null) — sem comunicação
5. Vencedor retransmite o Address Claim confirmando posse do SA

6.3 Curva de Torque do Motor

pub fn torque_at_rpm(&self, rpm: f64, throttle: f64) -> f64 {
    // Normaliza throttle para 0-1
    let t = throttle / 100.0;

    // Multiplicador do mapa de combustível
    let fuel_mult = match self.fuel_map {
        FuelMap::Economy  => 0.88,  // -12% de potência, -15% de consumo
        FuelMap::Standard => 1.00,  // Padrão de fábrica
        FuelMap::Power    => 1.08,  // +8% de potência, +10% de consumo
    };

    // Formato da curva de torque diesel com turbo:
    let shape = if rpm < 800.0 { 0.0 }        // Antes da marcha lenta
           else if rpm < 1400.0 {              // Rampa de subida
               0.65 + 0.35 * (rpm - 800.0) / (1400.0 - 800.0)
           }
           else if rpm <= 2100.0 { 0.95.. }   // PLATÔ de torque (característica turbo)
           else { 0.95 - ... };                // Queda acima do RPM nominal

    PEAK_TORQUE_NM * shape * t * fuel_mult
    // RPM 1400-2100: platô plano — aqui o diesel turbo é mais eficiente
}

6.4 Método tick() — Loop Principal do ECM

pub fn tick(&mut self, throttle_pct: f64, load_nm: f64, dt: f64) -> Vec<J1939Frame> {

    // ─ PASSO 1: Governador ─────────────────────────────────────────────────
    // Converte posição do acelerador em RPM alvo
    let throttle_demand_rpm = IDLE_RPM + (throttle / 100.0) * (rpm_limit - IDLE_RPM);
    let target_rpm = match governor_mode {
        AllSpeed => throttle_demand_rpm,
        Droop    => throttle_demand_rpm - (load_nm / PEAK_TORQUE_NM) * 100.0,
        // Em modo Droop: quanto maior a carga, mais o RPM cai
    };

    // ─ PASSO 2: Dinâmica do Motor (PI controller) ──────────────────────────
    let available_torque = self.torque_at_rpm(self.rpm, throttle);
    let net_torque = available_torque - load_nm;  // torque disponível - carga
    // a = torque / inércia → variação de RPM
    let rpm_accel = (net_torque / ENGINE_INERTIA_KGM2) * (60.0 / (2.0 * PI));
    // Integral do erro de RPM para eliminar offset estático
    self.rpm_error_integral += (target_rpm - self.rpm) * dt;
    self.rpm += (rpm_accel + governador_correction) * dt;
    self.rpm = self.rpm.clamp(0.0, MAX_RPM);

    // ─ PASSO 3: Pressão do Rail (CRDI) ────────────────────────────────────
    // Common Rail: pressão varia de 300 a 2000 bar conforme RPM e carga
    self.fuel_rail_pressure_mpa = 30.0 + rpm_norm * (throttle / 100.0) * 170.0;

    // ─ PASSO 4: Consumo de Combustível ────────────────────────────────────
    let power_kw = torque * rpm * PI / 30000.0;
    // BSFC (Brake Specific Fuel Consumption) ~210 g/kWh no ponto ótimo
    self.fuel_rate_lph = (power_kw * bsfc / 840.0 / 1000.0 * 3_600_000.0).max(1.5);

    // ─ PASSO 5: Modelo Térmico ────────────────────────────────────────────
    // Arrefecimento: aquece com carga, esfria gradualmente
    let tgt_coolant = 88.0 + load_heat * 6.0;
    self.coolant_temp_c += (tgt_coolant - self.coolant_temp_c) * dt * 0.015;
    self.oil_temp_c = self.coolant_temp_c + 12.0; // óleo ~12°C mais quente

    // ─ PASSO 6: Pós-Tratamento (DPF/SCR/EGR) ─────────────────────────────
    self.update_aftertreatment(dt);

    // ─ PASSO 7: Diagnóstico → Gera DTCs ──────────────────────────────────
    self.run_diagnostics();

    // ─ PASSO 8: Transmissão J1939 periódica ───────────────────────────────
    // EEC1 a cada 10ms, ET1 a cada 1s, etc.
    let mut frames = Vec::new();
    if self.t_eec1 >= 0.010 { frames.push(Builder::eec1(...)); }
    if self.t_et1  >= 1.000 { frames.push(Builder::et1(...));  }
    // ...
    frames
}

6.5 Pós-Tratamento (Aftertreatment)

fn update_aftertreatment(&mut self, dt: f64) {
    // DPF soot: acumula com carga, queima durante regeneração ativa
    if self.aftertreatment == DpfRegen {
        self.dpf_soot_pct -= 3.0 * dt; // queima ~3% por segundo
    } else {
        self.dpf_soot_pct += 0.0008 * load_factor * dt; // acúmulo normal
    }

    // Consumo de DEF: ~4% do volume de diesel
    self.def_level_pct -= fuel_rate_lph * 0.04 * dt / DEF_TANK_L * 100.0;

    // Eficiência do SCR (redução catalítica seletiva de NOx)
    self.scr_efficiency_pct = if self.def_level_pct > 5.0 && temp_ok {
        94.0 + load * 3.0  // >94% de eficiência em condições normais
    } else if self.def_level_pct > 2.0 {
        40.0               // DEF baixo: eficiência degradada
    } else {
        5.0                // Praticamente sem DEF = NOx alto = derate!
    };

    // NOx no escape (antes × eficiência do SCR)
    self.nox_tailpipe_ppm = self.nox_raw_ppm * (1.0 - self.scr_efficiency_pct / 100.0);

    // Transições de estado do aftertreatment
    if self.dpf_soot_pct > 75.0 && !self.regen_inhibited {
        self.aftertreatment = AftertreatmentState::DpfRegen; // regenerar!
    } else if self.def_level_pct < 2.0 {
        self.aftertreatment = AftertreatmentState::Derating; // derate!
    }
}

6.6 Diagnóstico Automático

fn run_diagnostics(&mut self) {
    // SPN 110, FMI 0 — Temperatura do arrefecimento acima do normal (crítico)
    if self.coolant_temp_c > 107.0 {
        self.add_dtc(110, 0, DtcSeverity::Red, "Coolant temp — Red Stop");
        self.red_lamp = true; // Lâmpada vermelha = PARAR IMEDIATAMENTE
    }

    // SPN 100, FMI 1 — Pressão do óleo abaixo do normal (crítico)
    if self.rpm > 600.0 && self.oil_pressure_kpa < 80.0 {
        self.add_dtc(100, 1, DtcSeverity::Red, "Oil pressure — Red Stop");
    }

    // SPN 3361, FMI 1 — Nível DEF crítico → derate de potência
    if self.def_level_pct < 2.0 {
        self.add_dtc(3361, 1, DtcSeverity::Red, "DEF critical — 60% power derate");
        self.rpm_limit = RATED_RPM * 0.60; // Limita RPM a 60%!
    }

    // SPN 3251, FMI 16 — DPF com fuligem alta (atenção)
    if self.dpf_soot_pct > 80.0 {
        self.add_dtc(3251, 16, DtcSeverity::Amber, "DPF soot high — regen required");
        self.amber_lamp = true;
    }
}

7.3 Dinâmica da Embreagem

fn update_clutch(&mut self, _engine_rpm: f64, torque_nm: f64, dt: f64) {
    match self.clutch_state {
        ClutchState::Filling => {
            // Fase de enchimento: pistão da embreagem enche com óleo
            // Duração: 80-150 ms (depende da temperatura — óleo quente = mais rápido)
            let fill_time = (0.15 - temp_factor).max(0.05);
            self.clutch_fill_pres += 10.0 / fill_time * dt; // Aumenta até 10 bar
            if timer >= fill_time { transition to Modulating }
        }
        ClutchState::Modulating => {
            // Fase de modulação: pressão sobe gradualmente de 10 → 25 bar
            // Isso permite transição suave sem solavanco
            self.clutch_fill_pres = 10.0 + ramp * 15.0;
            self.clutch_slip_pct  = (80.0 * (1.0 - ramp)).max(0.0);
            // Aquecimento da embreagem pelo deslizamento:
            self.clutch_temp_c += slip_pct * torque_nm * 0.00005;
            if timer >= 250ms { transition to Locked }
        }
        ClutchState::Locked => {
            self.clutch_fill_pres = 25.0; // pressão máxima de hold
            self.clutch_slip_pct  = 0.0;  // zero deslizamento
            // Resfriamento gradual da embreagem
            self.clutch_temp_c = (temp - 5.0 * dt).max(oil_temp);
        }
    }
}

11.1 Ciclo ABS (10 Hz)

// O ABS opera em 3 fases cicladas a ~10 Hz para cada roda individualmente:

fn run_abs(&mut self, dt: f64) {
    for w in &mut self.wheels {
        // DETECÇÃO: deslizamento > 20% com velocidade suficiente
        let slip_exceeded = w.slip_ratio > 0.20 && v_ref > 5.0;

        if slip_exceeded { w.abs_active = true; w.abs_cycles += 1; }

        if w.abs_active {
            w.abs_phase += dt * 10.0; // incrementa fase a 10 Hz
            if w.abs_phase > 1.0 { w.abs_phase -= 1.0; } // reset periódico

            w.valve_state = if w.abs_phase < 0.30 {
                // DUMP (0-30%): abre válvula de alívio, reduz pressão
                // Fluido volta ao reservatório, roda acelera de volta
                w.brake_pres_bar -= 40.0 * dt;
                AbsValveState::Dump
            } else if w.abs_phase < 0.55 {
                // HOLD (30-55%): isola o cilindro, pressão não muda
                // Roda recupera velocidade sem perder frenagem
                AbsValveState::Hold
            } else {
                // APPLY (55-100%): aplica pressão de volta controladamente
                w.brake_pres_bar += 60.0 * dt;
                AbsValveState::Apply
            };

            // Saída do ABS quando slip se recupera:
            if w.slip_ratio < 0.05 && w.speed > v_ref * 0.95 {
                w.abs_active = false;
                w.valve_state = AbsValveState::Normal;
            }
        }
    }
}

11.2 ESP — Electronic Stability Program

fn run_esp(&mut self, speed: f64, steer_deg: f64, yaw_actual: f64, ...) {
    // MODELO DE BICICLETA: calcula yaw rate desejado para a trajetória
    // Equação do modelo de bicicleta linear (subesterçado):
    // yaw_desejado = v × δ / (L × (1 + Kus × v²))
    // onde: v = velocidade, δ = ângulo de esterço, L = entre-eixos, Kus = gradiente
    let yaw_desired = v_ms * steer_rad / (2.7 * (1.0 + 0.005 * v_ms * v_ms));

    // ERRO DE YAW: diferença entre o que o veículo faz e o que deveria fazer
    self.esp_yaw_error = yaw_actual - yaw_desired_degs;

    if self.esp_yaw_error > 8.0 {
        // SOBREESTERÇAMENTO: traseira escorrega para fora
        // Correção: freia a roda dianteira externa para empurrar a frente
        self.esp_condition = EspCondition::Oversteer;
    } else if self.esp_yaw_error < -8.0 {
        // SUBESTERÇAMENTO: frente lava para fora
        // Correção: freia a roda traseira interna
        self.esp_condition = EspCondition::Understeer;
    }

    // RISCO DE CAPOTAMENTO: aceleração lateral > 0.8g
    if lat_g.abs() > 0.8 { self.esp_condition = EspCondition::RolloverRisk; }
}

DiagSession::Extended    // Sub=0x02: limpeza de DTCs, escrita, rotinas

// AUTENTICAÇÃO (Security Access — Seed/Key):
// 1. Scanner envia 0x27 0x01 (request seed, sub-function ímpar)
// 2. ECU gera seed aleatório: self.security_seed = LFSR(old_seed)
// 3. ECU responde: 0x67 0x01 [seed: 4 bytes]
// 4. Scanner calcula key = seed XOR 0xDEADBEEF  (simplificado; real usa AES)
// 5. Scanner envia 0x27 0x02 [key: 4 bytes]
// 6. ECU compara: se correto → SecurityLevel::Level1 (unlocked)
// 7. 3 tentativas falhas → lockout 10 segundos

fn svc_security_access(&mut self, req: &[u8], ts: f64) -> Vec<u8> {
    if req[1] % 2 == 1 {  // sub-function ímpar = request seed
        self.security_seed = self.security_seed.wrapping_mul(1664525).wrapping_add(1013904223);
        // Gerador de números pseudo-aleatório (LCG)
        vec![0x67, req[1], seed_bytes...]
    } else {               // sub-function par = send key
        let expected_key = self.security_seed ^ 0xDEADBEEF;
        if received_key == expected_key {
            self.security = SecurityLevel::Level1;
            vec![0x67, req[1]]  // positivo
        } else {
            self.security_attempts += 1;
            if self.security_attempts >= 3 {
                self.lockout_timer = 10.0; // 10 segundos de lockout!
                nrc(0x36) // ExceededNumberOfAttempts
            } else {
                nrc(0x35) // InvalidKey
            }
        }
    }
}

13. network_mgmt.rs — Network Management (OSEK NM)

Coordena o ciclo de vida dos nós CAN: acordar, operar e dormir coordenadamente.

13.1 Por que Network Management?

Em máquinas modernas, alguns ECUs ficam sempre alimentados pela bateria (BCM, relógio). Para economizar energia quando o veículo está desligado, o NM coordena todos os nós para entrar em modo sleep ao mesmo tempo. Se qualquer nó ainda precisar do barramento, o sleep é adiado.

13.2 Estados do Barramento

pub enum BusNmState {
    Off,           // Todos desligados
    WakingUp,      // Algum nó está iniciando (100 ms de transição)
    Active,        // ≥1 nó precisa do barramento — operação normal
    PrepShutdown,  // Todos os nós pediram sleep — contagem regressiva (2s)
    Sleep,         // Barramento silencioso — todos em modo low-power
}

13.3 Protocolo de Sleep

// Cada nó envia frame periódico "ALIVE" enquanto precisa do barramento
// Quando termina seu trabalho, envia "RING" (ready to sleep)
// O barramento vai para Sleep somente quando TODOS enviaram RING

fn tick(&mut self, powered_sas: &[u8], dt: f64) {
    // Verificar timeout de heartbeat por nó
    for node in &mut self.nodes {
        let silent_for = self.elapsed - node.last_nm_ts;
        if node.state == NmState::NormalOperation && silent_for > 0.5 {
            // Não recebeu heartbeat por 500ms = nó morto/desconectado
            node.state = NmState::BusSleep;
        }
    }

    // Máquina de estado do barramento:
    self.bus_state = match self.bus_state {
        BusNmState::Active => {
            if !any_active { PrepShutdown } else { Active }
        }
        BusNmState::PrepShutdown => {
            self.sleep_timer += dt;
            if any_active { Active }  // alguém acordou de volta
            else if self.sleep_timer >= 2.0 { Sleep }  // contagem completa
            else { PrepShutdown }
        }
        _ => { ... }
    };
}

fn update_hitch(&mut self, ground_speed_kmh: f64, dt: f64) {
    // Draft control: PID que ajusta profundidade para manter força constante
    let pos_error   = self.hitch_target_pct - self.hitch_position_pct;
    let draft_error = self.hitch_draft_target_kn - self.hitch_draft_force_kn;

    let speed = match self.hitch_control_mode {
        HitchMode::Position => pos_error * 6.0,   // Segue posição
        HitchMode::Draft    => -draft_error * 3.0, // Se draft > target: sobe engate
        HitchMode::Mixed    => pos_error * 3.0 - draft_error * 1.5,
        HitchMode::Float    => 0.0,                // Sem controle ativo
    };

    // Força de tração: depende de profundidade, velocidade, implemento, largura
    let depth_ratio  = (1.0 - self.hitch_position_pct / 100.0).max(0.0);
    let speed_factor = (ground_speed_kmh / 8.0).clamp(0.0, 2.0);
    let implement_k  = match self.implement_attached {
        Plow       => 14.0, // arado: alta resistência
        Disc       =>  9.0, // grade de discos
        Cultivator =>  5.5, // cultivador
    };
    // Modelo físico: força = profundidade × velocidade × k_implemento × largura
    let target_draft = depth_ratio * speed_factor * implement_k * width_factor;
}

pub fn tick(&mut self, dt: f64) {
    // ══ PASSO 1: Boot Sequence ═══════════════════════════════════════════
    // Gerencia os estados de boot de cada ECU e Address Claiming
    let trans_neutral = self.tcm.is_neutral;
    self.boot.engine_running = self.ecm.is_running();
    let boot_frames = self.boot.tick(dt, &mut self.gateway, trans_neutral);
    for f in boot_frames { self.gateway.transmit(f); }

    // ══ PASSO 2: Receber frames do ciclo anterior ════════════════════════
    // IMPORTANTE: cada ECU vê os frames do ciclo ANTERIOR (latência realista)
    let received: Vec<J1939Frame> = self.gateway.dispatched.clone();

    // ══ PASSO 3: ECM ═════════════════════════════════════════════════════
    let pto_load_nm       = self.implement.pto_torque_demand();
    let drivetrain_load   = if tcm.direction != Neutral { tcm.output_torque_nm * 0.05 } else { 0.0 };
    let total_engine_load = (drivetrain_load + pto_load_nm).clamp(0.0, 2000.0);
    let ecm_frames = if ecm_alive { ecm.tick(throttle, total_engine_load, dt) } else { vec![] };

    // ══ PASSO 4: TCM ═════════════════════════════════════════════════════
    let tcm_frames = if tcm_alive { tcm.tick(ecm.rpm, ecm.actual_torque_nm, throttle, brake, dt) } else { vec![] };

    // ══ PASSO 5: BCM ═════════════════════════════════════════════════════
    let bcm_frames = self.bcm.tick(self.ecm.alternator_v, dt);

    // ══ PASSO 6: ICM ═════════════════════════════════════════════════════
    let icm_frames = self.icm.tick(&received, dt);
    // Atualização direta (dados ainda não propagados via CAN):
    self.icm.engine_rpm       = self.ecm.rpm;
    self.icm.fuel_level_pct   = self.ecm.fuel_level_pct;
    // ... (outros campos)

    // ══ PASSO 7: HCM ═════════════════════════════════════════════════════
    let hcm_frames = self.hcm.tick(ecm.rpm, hitch_cmd, loader_cmd, tilt_cmd, dt);

    // ══ PASSO 8: ABS/ESP/TCS ═════════════════════════════════════════════
    let (tcs_cut, abs_frames) = self.abs.tick(speed, brake, throttle, steer, yaw, lat_g, dt);

    // ══ PASSO 9: UDS (diagnóstico) ═══════════════════════════════════════
    self.uds_ecm.tick(dt); // Expira sessões, gerencia lockout de segurança

    // ══ PASSO 10: NVM ════════════════════════════════════════════════════
    self.nvm.tick(self.elapsed, dt);
    // Sincroniza horas de motor para NVM a cada minuto:
    if (self.elapsed % 60.0) < dt { self.nvm.write_f64("engine_hours", ecm.engine_hours); }

    // ══ PASSO 11: Network Management ═════════════════════════════════════
    let powered_nodes: Vec<u8> = self.boot.ecus.iter().filter(|e| e.is_online())
                                                        .map(|e| e.sa).collect();
    self.net_mgmt.tick(&powered_nodes, dt);

    // ══ PASSO 12: Submeter todos os frames para o gateway ════════════════
    for f in [ecm_frames, tcm_frames, bcm_frames, icm_frames, hcm_frames, abs_frames].into_iter().flatten() {
        self.gateway.transmit(f);
    }

    // ══ PASSO 13: Gateway arbitra e despacha ════════════════════════════
    // Ordenação por prioridade de CAN ID, distribuição para todos os ECUs
    self.gateway.tick(dt);

    // ══ PASSO 14: Injeção de falhas ══════════════════════════════════════
    if self.fault_active { self.apply_fault(); }

    self.elapsed += dt;
}

    for i in 0..80 {

    let filled = ((frac * 80.0).floor() as usize).min(80);
    for i in 0..filled {

20.1 Filtro Madgwick AHRS

O Madgwick AHRS (Attitude and Heading Reference System) é um algoritmo de fusão de sensores que combina acelerômetro, giroscópio e magnetômetro em um quaternion de atitude. É o mesmo algoritmo usado em drones, robôs e sistemas de piloto automático. 
// Algoritmo Madgwick em pseudocódigo:
const BETA: f64 = 0.1;  // Ganho do filtro (0.01=lento, 0.5=rápido)

fn madgwick_update(&mut self, dt: f64) {
    // 1. Normalizar acelerômetro e magnetômetro
    let (ax, ay, az) = normalise(accel_cal);
    let (mx, my, mz) = normalise(mag);

    // 2. Calcular referência do campo magnético terrestre
    //    (h = quaternion_rotate([mx,my,mz] by q))
    let bx = sqrt(hx² + hy²);  // componente horizontal do campo terrestre
    let bz = hz;                // componente vertical

    // 3. Calcular função objetivo e Jacobiana
    //    f = [f_acc(q, a_ref, a_meas), f_mag(q, b_ref, m_meas)]
    //    J = Jacobiana de f em relação a q

    // 4. Calcular gradiente: ∇f = Jᵀf (normalizado)
    let (s0, s1, s2, s3) = gradient_descent(f, J);

    // 5. Integrar giroscópio com correção do gradiente
    q_dot = 0.5 × q ⊗ [gx, gy, gz]  - BETA × ∇f

    // 6. Integrar quaternion
    q += q_dot × dt
    q.normalise()
}

// Estado Kalman por alvo: [range, range_rate, lateral_pos, lateral_vel]
// Modelo de processo: constante de velocidade

fn kalman_predict(&mut self, dt: f64) {
    // Propagação: x[k+1] = F × x[k]
    self.kf_x[0] += self.kf_x[1] × dt;  // range += range_rate × dt
    self.kf_x[2] += self.kf_x[3] × dt;  // lateral_pos += lateral_vel × dt
    // Covariância cresce com tempo (incerteza aumenta sem medição)
    self.kf_p[0] += self.kf_p[1]×dt + 0.1×dt²;
}

fn kalman_update(&mut self, z_range: f64, z_rate: f64, z_azimuth: f64) {
    let r_cov = 1.0;  // variância da medição
    let k = self.kf_p[0] / (self.kf_p[0] + r_cov);  // ganho Kalman
    self.kf_x[0] += k × (z_range - self.kf_x[0]);    // inovar estado
    self.kf_p[0] *= 1.0 - k;                           // reduzir incerteza
    // Recalcular TTC: se aproximando (range_rate < 0), TTC = range / |rate|
    self.ttc_s = if range_rate < -0.1 { -range / range_rate } else { ∞ };
}

// Para cada raio LIDAR (azimuth × elevação), intersecta com cada obstáculo:
pub fn ray_intersect(obs: &WorldObstacle, origin, direction, z_at_range) → Option<f64> {
    // AABB = Axis-Aligned Bounding Box
    let inv_dx = 1.0 / dir_x;
    let inv_dy = 1.0 / dir_y;

    // Calcular entradas/saídas nos eixos X e Y
    let t1x = (obs.x - obs.half_l - origin.x) × inv_dx;  // entrada X
    let t2x = (obs.x + obs.half_l - origin.x) × inv_dx;  // saída X
    let t1y = (obs.y - obs.half_w - origin.y) × inv_dy;  // entrada Y
    let t2y = (obs.y + obs.half_w - origin.y) × inv_dy;  // saída Y

    // A interseção existe se os intervalos X e Y se sobrepõem
    let tmin = max(min(t1x, t2x), min(t1y, t2y));
    let tmax = min(max(t1x, t2x), max(t1y, t2y));

    if tmax ≥ tmin && tmin > 0 { Some(tmin) } else { None }
}

fn run_acc(&mut self, speed_ms: f64, lead_range: f64, dt: f64) {
    let set_speed = self.acc_set_speed_kmh / 3.6;

    // PASSO 1: Calcular velocidade alvo baseada no gap para o veículo à frente
    let safe_dist = speed_ms × self.acc_headway_s;  // ex: 80km/h × 2s = 44m
    let dist_error = lead_range - safe_dist;          // erro de distância
    let gap_speed  = speed_ms + dist_error × 0.5;    // velocidade para fechar gap
    let target_speed = gap_speed.min(set_speed);      // limitado pela velocidade setada

    // PASSO 2: Controlador PI de velocidade
    let speed_error = target_speed - speed_ms;
    self.integral += speed_error × dt;
    let control = speed_error × 0.08 + self.integral × 0.004;
    //                          ↑ Kp              ↑ Ki

    // PASSO 3: Saída como throttle ou brake
    if control > 0.02  { throttle = control.clamp(0, 1); brake = 0; }
    else                { brake = (-control).clamp(0, 0.8); throttle = 0; }
}

24.3 LKA — Lane Keeping Assist (Controlador PD)

fn run_lka(&mut self, offset: f64, heading_err: f64, speed_ms: f64, dt: f64) {
    if speed_ms < 3.0 { return; }  // só ativo acima de 3 m/s

    let kp = 4.0 × (speed_ms / 30.0).min(1.0);  // ganho proporcional aumenta com velocidade
    let ki = 0.3;

    self.lka_integral += offset × dt;
    // Correção = proporcional ao offset + integral + derivativo do heading
    let steer = -(kp × offset + ki × self.lka_integral + 0.5 × heading_err);
    self.lka_steer_cmd = steer.clamp(-6.0, 6.0);  // ±6° de correção máxima
}

// O VCM recebe requisições de torque de múltiplas fontes e calcula o mínimo:
pub struct TorqueCoordination {
    max_engine_torque_nm:    f64,  // limite por segurança/modo limp
    abs_torque_limit_nm:     f64,  // ABS/TCS: corte para reduzir slip
    ad_torque_request_nm:    f64,  // Sistema autônomo: reduz ao frear
    commanded_torque_nm:     f64,  // = min(todos os limites acima)
    limiting_source:         &str, // quem está limitando agora
}

fn compute_final(&mut self) {
    // A "votação" de torque: sempre usa o limite mais restritivo
    let (min_torque, source) = [
        (max_engine, "VCM-max"),
        (abs_limit,  "ABS/TCS"),
        (ad_request, "AD-ctrl"),
    ].iter().min_by(torque_value);

    self.commanded_torque_nm = min_torque;  // ECM vai seguir este valor
}
